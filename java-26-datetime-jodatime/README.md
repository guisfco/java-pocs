# Java 26 Date and Time POC

This POC explores different date and time APIs in Java, comparing the legacy `java.util.Date` and `java.util.Calendar`, the modern `java.time` API (JSR-310), and the popular third-party library Joda-Time. It demonstrates how to handle time zones, formatting, parsing, and duration/period calculations.
