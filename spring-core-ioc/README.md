# Spring Core IoC POC

This POC demonstrates the fundamental concepts of Spring's Inversion of Control (IoC) and Dependency Injection (DI). It showcases manual dependency injection as a baseline and compares it against Spring container-managed beans using Java-based configuration, component scanning, and implicit constructor injection.
