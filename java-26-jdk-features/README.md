# Java 26 JDK Features POC

This POC explores modern features introduced across various JDK releases up to JDK 26. It covers features like Virtual Threads, Pattern Matching, Record Patterns, Sequenced Collections, Stream Gatherers, Scoped Values, and the HTTP/3 Client.
